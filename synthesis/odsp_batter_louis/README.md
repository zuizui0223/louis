# ODSP × batter × Louisiana：多次元ニッチから経験環境の維持へ

**研究統合メモ v1（2026-10-23）／実測効果の新規推定ではない**

## 中心質問

**環境に多くの状態があること、動物が個体ごとに違う状態を選ぶこと、そして経験環境が時間的に安定することは、いつ結び付き、いつ分離するのか？**

今回の既知真値モデルで示した二つの非自明な結果は、(1) 状態の厚み・個体差・分散がすべて等しくても、利用の時間順序を変えるだけで連続状態維持は逆転する、(2) 環境状態のエントロピーが等しくても、個体が必要とする状態が到達可能かどうかは異なりうる、というものである。

**注意：** 数学的反例は生物学の新しいデータではない。以下の3リポの支持済み実証結果と、その結果を因果的に連結する仮説は区別する。

## 1. 三つの既存研究は異なる生態学的レイヤーを測っている

## 2. 既知真値の反例：同じ利用分布でも時間順序が違えば結論は逆

状態は0と1、各時刻で各50%が利用可能とする。2個体が各8時刻で記録した状態を、状態の度数を変えずに並べ替える。

| | 個体1 | 個体2 |
|---|---|---|
| A：まとまった利用 | 00000011 | 11111100 |
| B：頻繁な入れ替え | 01010000 | 10101111 |

両ケースとも、利用状態エントロピー **0.6931 nats**、個体IDとの相互情報量 **0.1308 nats**、平均個体内状態分散 **0.1875**、状態頻度から求めた独立利用の同一状態率 **0.625** で完全に一致する。

しかし、連続する2時点に同じ状態を利用する実測割合はAが **6/7 = 0.8571**、Bが **3/7 = 0.4286**。独立した静的選好モデルからの超過はAで **+0.2321**、Bで **−0.1964** と符号が反転する。

よって **静的な厚み・個体性・利用分散は、時間的な連続利用を決定しない**。時間順序を別に測る必要がある。これは、King Railで水深分散型SRIに加えて、実際の時間順序を利用した保持指標を検証したことと対応する。ただし、人工の二値分散比は原著のSRIではない。

また、2個体が両方とも8時刻をすべて状態0で過ごせば、個体IDと利用状態の情報量は0だが、連続同一状態率は1となる。**個体間の差は、経験状態が時間的に安定するための必要条件ではない**。この場合、静的選好基準からの追加保持は0なので、絶対的な安定性と行動的な追加安定化も区別する。

## 3. より生物学的な非自明性：状態の総厚み ≠ 適合状態に到達できること

個体が必要とする状態を0とする。異なる3状態の**独立に測定された到達可能性**を、A=[0.5,0.5,0] と B=[0,0.5,0.5] とする。どちらも環境状態のエントロピーは **ln 2 = 0.6931** だが、個体が必要とする状態0の到達可能質量Kは Aで **0.5**、Bで **0**。

一般に、個体iの受容可能な状態集合G_iを、将来の応答データとは独立の訓練期間に定義して、

\[
K_i(t)=\sum_{s\in G_i}a^{\mathrm{reachable}}_{i,t}(s)
\]

とする。選好強度w=5の人工的な選択モデルでは、

\[
P(\mathrm{acceptable}\mid t)=\frac{wK_i(t)}{wK_i(t)+1-K_i(t)}
\]

となり、Aでは5/6、Bでは0。Bではどんな局所的な選択能力があっても、現在の到達可能集合内に必要な環境状態がない。AでもKが正というだけでは実際にその状態を選ぶとは限らず、移動コスト、リスク、学習、他個体との相互作用が関与しうる。

**次の中心仮説：環境の総多様性よりも、個体ごとに適合する状態の到達可能な割合が、経験環境の安定性と状態切替を制約する。**

これは既存King RailデータからKを推定したという意味ではない。ODSPの観測利用分布のエントロピーを独立した到達可能性の代用品にしてはならない。

## 4. 既存研究から導いた、次に反証できる生態学的予測

**P1・総多様性と到達可能性を分ける。** 同じ総環境状態エントロピー、季節、個体を比較しても、Kが低いほど過去の適合状態を維持しにくい。Kが同じなら、個体差のある選択・移動の順序が残余の安定性を説明するかを問う。

**P2・個体性を機能と同一視しない。** 保留期間でも再現する個体の鉛直／水深分布形状があっても、それが環境緩衝や採餌成功へつながらない可能性を明示的な対立仮説にする。滞在パッチや行動状態の混合で説明できれば、能動的制御仮説は弱まる。

**P3・局所候補がなくなったときの限界。** 個体に適合する状態のKが低下すると、局所的な状態維持が難しくなり、状態そのものの切替、広域移動、退出という異なる反応が観察されうる。どの反応が起こるかは個体と地形・移動制約に依存する。広域移動の閾値を現段階で示したわけではない。

## 5. 同じ生態系で3段階を一度に検証するための最低限のデータ

同一個体の反復位置データ、各時刻の利用場所の水深／高度、**使われなかった場所と旧使用地点を含む**動的環境ラスタ、到達可能な経路・距離、個体の行動状態が必要。望ましい状態帯は結果観測より前の訓練期間に定義する。

検証を（1）状態支持の厚み、（2）保留セッションに再現する個体固有の利用分布、（3）時間順序を考慮した状態連続性、（4）**旧地点と新地点の同時刻環境**の比較、（5）地理的滞在や経路制約を保持する対照、と段階的に分ける。

King Railの現在の公表資料では、GPS軌跡と各水深イベントの対応づけが未確定なので（4）を推定できない。Louisianaで続けたUSGSの水指数外部検証も、元の月別多センサー指標とLandsatだけの再構成で時間変化方向の一致基準に届かず、反事実的な移動利益は未推定である。

**投稿の扱い：** ODSPはニッチ厚みと転移、batterは個体の鉛直利用、LouisianaはKing Rail水深緩衝という原稿をそれぞれ独立に残す。カリフォルニア4種比較も別の探索的原稿。数理的な反例は新規野外結果と数えず、将来の共同実証の仮説・検証計画として使う。
