# louis

Independent ecological project on the spatiotemporal ecology of King Rail and other secretive marsh birds in southwest Louisiana.

## Scientific origin

This project grew from an EOG anomaly: future King Rail detection retained a small history-dependent signal, yet all six tested simple local-propagation worlds were falsified.

The project therefore asks **what produces temporal structure when simple local spread does not**.

Current competing hypotheses:

1. persistent site use / latent occupancy;
2. stable habitat or salinity filtering;
3. synchronized regional detectability;
4. open-population dynamics beyond the tested local network.

See [docs/idea_origin_from_eog.md](docs/idea_origin_from_eog.md).

## Boundary

EOG is provenance only. Ecological claims here require direct analysis of marsh-bird observations.
