# Ecological synthesis: movement as state-mismatch regulation

## Core biological idea

The two seed systems are not fundamentally about observation memory or geographic propagation.

They point to a more biological rule:

> **Movement is one way organisms reduce mismatch between their internal ecological requirements and the environmental state they currently experience.**

Let:

- \(S_i(t)\) = the internal state / ecological requirement of individual \(i\);
- \(E(x,t)\) = environmental state at location \(x\) and time \(t\);
- \(D[S_i(t),E(x,t)]\) = ecological mismatch;
- \(C(x,t)\) = opportunity/connectivity for movement.

A minimal behavioural expectation is:

\[
P(\text{move}) \uparrow
\quad \text{as} \quad
D[S_i(t),E(x,t)] \uparrow,
\]

but only when movement opportunity is available.

This is not claimed as a brand-new optimality principle by itself. The scientific value is in using two very different systems to resolve **how mismatch is reduced**.

## Route A — remain because the place still matches

### Azores yellow eel

During the yellow growth phase, a local pool can continue to supply an acceptable refuge/resource state.

If mismatch remains low:

\[
D[S_{yellow},E(pool,t)] \approx 0
\]

then movement capacity can remain latent.

Persistence is achieved by:

> **stay in place because the state remains suitable.**

This is anchoring.

## Route B — move locally because the place no longer matches

### Dynamic wetland bird

Water depth, vegetation accessibility and edge structure can change inside a familiar marsh.

When the state at the current point changes:

\[
D[S_{bird},E(x_t,t+1)] > 0,
\]

the animal can reduce mismatch without abandoning the broader home range by moving to another internal patch \(x_{t+1}\):

\[
D[S_{bird},E(x_{t+1},t+1)]
<
D[S_{bird},E(x_t,t+1)].
\]

Persistence is achieved by:

> **move in geographic space to remain in ecological-state space.**

This is environmental-state tracking.

## Route C — internal state changes while the landscape does not

### Eel silvering

The landscape can remain similar while the organism's own state changes from growth/pre-migrant to migratory.

Then mismatch can rise even without environmental deterioration:

\[
S_{FIII} \rightarrow S_{FIV/FV}.
\]

A refuge that was acceptable for growth is no longer the relevant endpoint for a migratory individual.

Movement is therefore released by an **internal state transition**, and landscape connectivity/barriers determine how fully that motivation can be expressed.

## The concrete ecological predictions

### P1 — movement responds to mismatch, not distance alone

At the same geographic distance, movement should be more likely when environmental state differs strongly from the current requirement.

### P2 — stable environments produce anchoring

When environmental state at a familiar site remains inside the individual's acceptable state range, relocation should be suppressed.

### P3 — dynamic heterogeneous environments produce internal tracking

When the current microhabitat becomes unsuitable but an alternative suitable state exists nearby, animals should relocate locally rather than abandon the broader familiar area.

### P4 — internal state can reverse the same landscape response

The same barrier, refuge or habitat configuration can have different behavioural consequences for different life-history states.

### P5 — broad relocation occurs when local compensation fails

If no reachable location inside the familiar area restores low mismatch, movement should expand beyond that area.

## Why the two repositories remain distinct

This synthesis does not merge the papers.

### azores

Tests **internal-state gating of mobility and landscape resistance**.

The central question is whether movement readiness changes how landscape opportunity is translated into realised migration.

### louis

Tests **environmental-state fidelity**.

The central question is whether movement through a dynamic wetland stabilises the environmental conditions actually experienced by an individual.

## Stronger future synthesis

If both programmes succeed independently, a later comparative paper can test:

> **Animals persist in a landscape by regulating organism–environment mismatch: stable landscapes favour anchoring, dynamic heterogeneous landscapes favour within-area tracking, and internal state transitions can trigger broad movement even without local habitat deterioration.**
