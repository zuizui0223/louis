# External generality panel for within-area state tracking

## Purpose

The Lake Erie King Rail dataset remains the primary direct test because its used points have **time-matched local random points**.

Two fully public external systems are added to test whether the broader biological pattern generalises beyond King Rail.

They are not substitutes for the Lake Erie SRI test.

## System G1 — Senegal Delta Black-tailed Godwit

Source:
- Craft et al. 2025, *Journal of Applied Ecology*
- DOI: 10.1111/1365-2664.14827
- Dryad: 10.5061/dryad.4tmpg4fm3

Open data include:

- raw GPS locations for individually identified birds;
- timestamp, longitude, latitude, bird ID;
- wet/dry-season utilization distributions;
- habitat-use summaries;
- analysis scripts.

Published biological pattern:

- early nonbreeding use of floodplain wetlands and newly planted rice;
- movement toward more recently sown rice as crops mature;
- later movement away from drying rice fields into natural wetlands as floodwaters recede.

### Role in this programme

This is a **dynamic habitat-tracking generality test**.

It already demonstrates that birds redistribute as the location of suitable habitat changes.

What remains new for this programme is not to repeat the published seasonal habitat-shift result. It is to ask whether:

> **environmental-state displacement is systematically smaller than geographic displacement along individual trajectories.**

### Limitation

The Dryad archive contains raw GPS and seasonal habitat products, but not an event-matched random availability design equivalent to Lake Erie.

Therefore it cannot replace SRI.

It can test a weaker generality prediction:

> birds can move large distances while maintaining or repeatedly reacquiring similar functional habitat states.

## System G2 — California waterfowl under dynamic flooding

Source:
- USGS data release DOI: 10.5066/P922KDU6
- associated report DOI: 10.3133/ofr20201102

The public release links GPS telemetry with open-water habitat maps updated at **16–18 day intervals**.

The report shows:

- duck locations strongly track classified flooded habitat;
- feeding locations remain concentrated near primary roosts;
- foraging distance varies with hydrological region and season;
- highly reliable water areas can receive repeated use even under drought.

### Role in this programme

This system tests the **hydrological-opportunity axis**:

> when suitable flooded habitat remains locally available, movement can remain spatially constrained; when water availability changes, movement scale should expand or redistribute.

This is the same biological boundary proposed for King Rail:

```text
local suitable state retained -> internal tracking / residency
local suitable state lost     -> broader relocation
```

### Limitation

The currently indexed public derived tables emphasize species/location habitat classification and movement summaries; individual-level identity in every derived table is not yet verified.

Therefore this system is a **population-level generality panel** unless individual-resolved telemetry can be recovered from the associated release.

## Three-level Louisiana evidence architecture

### Level 1 — direct individual test

Lake Erie King Rail:

> used-state trajectory versus time-matched local availability.

Primary metric: SRI.

### Level 2 — same-species boundary

South Carolina King Rail:

> seasonal environmental change can exceed local compensation and produce km-scale home-range relocation.

### Level 3 — cross-taxon generality

Godwit + California ducks:

> dynamic wetland state redistributes bird space use across much larger spatial scales.

## General biological prediction

The key quantity is not simple site fidelity.

It is the **spatial distance required to restore a suitable environmental state**.

Prediction:

> **the larger the distance to the nearest currently suitable state, the larger the realised movement response.**

This gives a continuous ecological hypothesis:

- suitable state remains at current location -> anchoring;
- suitable state moves inside home range -> micro-niche tracking;
- suitable state disappears locally but remains nearby -> home-range shift;
- suitable state disappears regionally -> broad relocation/migration.

## Novelty boundary

Resource tracking and niche tracking are established.

The potentially new contribution is to connect movement scale to **the spatial displacement of suitable state itself**, and to test that idea from individual matched availability through population-scale dynamic wetland systems.
